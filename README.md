## Deploy

1. Fork or clone this repo
2. Connect to [Netlify](https://netlify.com) → New site from Git
3. Add custom domain `loancrack.pro` in Netlify settings
4. Update DNS at your registrar (CNAME → Netlify)
5. Replace `ca-pub-XXXXXXXXXX` with your AdSense publisher ID
6. Replace `G-XXXXXXXXXX` with your Google Analytics measurement ID
